# Expense Tracker

## Overview

A full-stack Expense Tracker application built using React, Node.js, Express, MongoDB, JWT Authentication, Tailwind CSS, and Recharts.

## Features

* User Registration
* User Login
* JWT Authentication
* Protected Routes
* Add Expenses
* Edit Expenses
* Delete Expenses
* Search Expenses
* Category Filtering
* Dashboard Statistics
* Recent Transactions
* Expense Category Pie Chart
* Responsive UI

## Tech Stack

Frontend:

* React
* Vite
* Tailwind CSS
* Axios
* Recharts

Backend:

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
